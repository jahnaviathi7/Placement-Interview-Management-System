# Viva Questions

### What is this project?
A web-based Placement and Interview Management System that connects students, recruiters and administrators.

### Why React?
React provides reusable UI components and efficient client-side rendering.

### Why FastAPI?
FastAPI is lightweight, fast and automatically provides OpenAPI/Swagger documentation.

### Why JWT?
JWT allows stateless authentication and lets the API identify the logged-in user.

### Why SQLite?
SQLite is simple for a student project and requires no separate database server. It can later be migrated to PostgreSQL/MySQL.

### What is role-based access?
Different users receive different permissions. Students apply for jobs, recruiters manage recruitment and admins manage the system.

### What is CRUD?
Create, Read, Update and Delete operations. This project mainly demonstrates Create, Read and Update operations.

### What can be added later?
Resume upload, email notifications, interview feedback forms, calendar integration, PostgreSQL, analytics charts and AI-based resume-job matching.
